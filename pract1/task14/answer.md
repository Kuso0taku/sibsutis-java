# Наследование взрывает комбинации

## Проблема

Форматы `Online`/`Classroom`/`Hybrid` × оплаты `Free`/`Fixed`/`Subscription`
при наследовании дают 3 × 3 = 9 подклассов. Каждая новая ось умножает
количество классов: +1 формат = ещё 3 класса, +1 оплата = ещё 3.

## Решение

Разделили независимые оси на компоненты:

- `CourseFormat` (3 реализации + `SelfPaced`);
- `PaymentPolicy` (3 реализации + `Installment`);
- `CourseOffer` просто держит оба компонента.

Классов стало 3 + 3 + 1 вместо 9, а комбинируются оси на лету.
Новый формат или оплата — один новый класс, `CourseOffer` не меняется.
